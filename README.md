Minimum Distance
Description

This is a small C++ program that solves an algorithmic challenge:

Given a list of horse powers, the program calculates the minimum distance (difference) between any two horse powers.

The approach used is:

  -Sort the array of horse powers using QuickSort.

  -Compute the minimum difference between consecutive elements in the sorted array.

This ensures efficient computation and simple implementation.

Features

  -Uses QuickSort to sort the input array.

  -Returns the minimum difference between horse powers.

  -Lightweight and easy to understand.
